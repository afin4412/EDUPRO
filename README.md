# 🎓 EDUPro – E-Learning Platform (UI/UX Design)

A modern and user-focused e-learning platform designed to simplify the journey of students and professionals seeking higher education and certification courses.  
This project focuses on **clarity, accessibility, and engagement**, providing a smooth and personalized learning experience through intuitive UX.

---

## 🎯 Project Overview
EDUPro is a digital platform created to bridge the gap between learners and institutions.  
The goal was to design an interface that enables users to **browse, enroll, and track progress** easily while maintaining a clean, motivating, and trustworthy visual identity.

---

## 🧩 Key Objectives
- Simplify the **course discovery** and **enrollment** process  
- Ensure **accessibility** and **ease of navigation** across all user levels  
- Create a **dashboard experience** for tracking learning progress  
- Maintain a **clean, academic aesthetic** that inspires learning  

---

## 🧠 UX Process
1. **User Research & Personas** – Identified students’ needs, goals, and challenges  
2. **Information Architecture** – Structured categories for quick course exploration  
3. **Wireframing** – Defined content layout and navigation flow  
4. **High-Fidelity UI Design** – Created visual consistency using minimal colors and clear typography  
5. **Prototyping & Feedback** – Built interactive flows and refined through user testing  

---

## 🛠️ Tools Used
- **Figma** – UI Design, Wireframing, and Prototyping  
- **Adobe XD** – Interaction Design  
- **Illustrator / Photoshop** – Visual assets and icons  

---

## 🎨 Design Highlights
- Clean onboarding flow to guide new users  
- Personalized dashboards for progress tracking  
- Modular card layout for courses and instructors  
- Consistent color palette and accessible contrast ratios
